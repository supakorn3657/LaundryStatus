# สถานะตู้ซักผ้าหอพัก

โปรแกรม Java บนคอมเครื่องเดียว สำหรับดูสถานะตู้ซักผ้าที่หอ
ระบุตัวตนด้วยเลขห้อง ข้อมูลเก็บลงไฟล์ในเครื่อง

หลังกดรันมี 3 จอ
1. เข้าสู่ระบบ ใส่เลขห้องและรหัสผ่าน 4 หลัก
2. จอตู้ 6 เครื่อง โชว์สถานะอย่างเดียว
3. กดเครื่องแล้วเปิดจอของเครื่องนั้น
   - ว่าง: เลือกโหมด แล้วกดเริ่มซัก
   - กำลังซัก: ดูเวลาที่เหลือกับเวลาซักเสร็จ ปุ่มกลับ
   - รอเก็บผ้า: เก็บผ้าได้เฉพาะห้องที่กดเริ่มซัก

สถานะมี 3 แบบ
- ว่าง
- กำลังซัก
- รอเก็บผ้า

โหมดซัก
- ปั่นทั่วไป 45 นาที
- ปั่นเร็ว 15 นาที
- ปั่นผ้านวม 70 นาที

รันโปรแกรมที่ GUI/LoginView.java
